*parse.nvim.txt*  Competitive Companion receiver for Neovim

===============================================================================
INTRODUCTION                                                     *parse.nvim*

parse.nvim receives Competitive Companion payloads and writes a source file plus
sample test data using explicitly selected handlers based on the author's old
Python receiver scripts.

Routing is manual by default. Automatic judge detection is opt-in.

===============================================================================
COMMANDS                                                   *parse.nvim-commands*

:ParseUse [handler]
    Select the handler used for future payloads. With no argument, opens a
    picker. `manual` clears the sticky handler and prompts on each payload.
    `auto` enables URL/group/source detection and falls back to the picker.

    Handlers: cf, atcoder, qoj, codechef, cses, usaco, uva, oly, 603, 603p,
    camp, hw, hw_old.

:ParseStart
    Start the HTTP listener.

:ParseStop
    Stop the HTTP listener.

:ParseStatus
    Show listener and parser state.

===============================================================================
CONFIGURATION                                                 *parse.nvim-opts*

Default routing:
>
  opts = {
    parser = nil, -- manual; "auto" is opt-in
  }
<

The listener defaults to http://127.0.0.1:10043/.
