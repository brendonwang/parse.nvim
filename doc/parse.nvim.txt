*parse.nvim.txt*  Competitive Companion receiver for Neovim

===============================================================================
INTRODUCTION                                                     *parse.nvim*

parse.nvim receives Competitive Companion payloads and creates source files,
CMake targets, and numbered sample files using explicitly selected handlers.
Samples use the original gen.py layout under <root>/data/<cur>/<problem>/ and
are written only when the source file is first created. Re-importing an existing
problem leaves testcase files unchanged. parse.nvim does not run the samples.

Routing is manual by default. Automatic judge detection is opt-in.

===============================================================================
COMMANDS                                                   *parse.nvim-commands*

:ParseUse [handler]
    Select the handler used for future payloads. With no argument, opens a
    picker. `manual` clears the sticky handler and prompts on each payload.
    `auto` enables URL/group/source detection and falls back to the picker.

    Handlers: cf, atcoder, qoj, codechef, cses, usaco, uva, oly, 603, 603p,
    camp, hw, hw_old.

:ParseStart
    Start the HTTP listener.

:ParseStop
    Stop the HTTP listener.

:ParseStatus
    Show listener and parser state.

:ParseNew [cf|usaco] [name]                                    *:ParseNew*
    Create and open a new C++ file from the CF or USACO template in the current
    buffer's directory, or the working directory for an unnamed buffer.
    Adds .cpp if omitted; prompts if no name is given. Without an explicit
    template, uses the active handler's template (CF by default).
    Uses configured templates, then <base_dir>/algo/library/template_cf.cpp or
    template_usaco.cpp, then bundled templates. Adds a CMake target and uses
    the normal configure settings. Existing files are refused. Cancelling the
    prompt has no effect. Names must be plain filenames, not paths.

    Examples: :ParseNew cf a
              :ParseNew usaco gates.cpp
              :ParseNew cf

:ParseContest [--dir path] <names|range|count>                  *:ParseContest*
    Create sources and CMake targets from names, a range (a-f), or a count (10).
    Without --dir, use the current buffer's directory. With --dir (or -d),
    use a directory relative to base_dir / BASE_DIR, or an absolute directory
    inside that base. Create its CMakeLists.txt and register it in the base
    CMakeLists.txt with add_subdirectory(), preserving existing entries.

    Examples: :ParseContest a-f
              :ParseContest --dir contests/round_123 a-f
              :ParseContest first 10 --dir classes/week_1

:ParseLast
    Inspect the most recently received payload in a scratch buffer.

===============================================================================
CONFIGURATION                                                 *parse.nvim-opts*

Default routing:
>
  opts = {
    parser = nil, -- manual; "auto" is opt-in
  }
<

The listener defaults to http://127.0.0.1:10043/.
